# Ouweis Mansouri — Portfolio

Portfolio de web designer & développeur créatif, publié sur [ouweisbts.github.io/Ouweismansouri](https://ouweisbts.github.io/Ouweismansouri/).

## Structure

- `index.html` — page d'accueil éditoriale claire (`assets/css/home.css`, `assets/js/home.js`)
- `projets/` — études de cas : Dubaï Center (client), Anas Food (proposition de refonte), Maison Sable et Atelier Heure (concepts)
- `anas-food/` — site complet de la refonte Anas Food (autonome : ses propres styles, scripts et images)
- `atelier-heure/` — site d'une maison horlogère fictive (autonome : GSAP, ScrollTrigger et Lenis servis localement)
- `concepts/` — prototype en ligne de Maison Sable (marque fictive)
- `assets/css/main.css`, `assets/js/main.js` — styles et interactions des études de cas
- `assets/vendor/` — GSAP 3.12.5 + ScrollTrigger, Lenis 1.1.13 (servis localement)
- `ancien-portfolio.html` — l'ancienne version (thème DevFolio), conservée pour archive

Site statique, sans étape de build : ouvrir `index.html` suffit.
